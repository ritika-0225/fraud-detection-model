# Transaction Fraud Detection Using Machine Learning
This project focuses on detecting fraudulent transactions using Machine Learning techniques and data analysis.

## Project Overview
The objective of this project was to build a model capable of identifying fraudulent transactions while handling class imbalance and improving fraud detection accuracy.

## Technologies & Libraries Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Key Concepts Applied
* Data Cleaning
* Exploratory Data Analysis (EDA)
* Data Visualization
* Feature Encoding
* Classification Models
* Model Evaluation
* SMOTE (Synthetic Minority Oversampling Technique)

## ML Models Used
* Logistic Regression
* Random Forest Classifier

## Results
Random Forest outperformed Logistic Regression by achieving better fraud detection performance with fewer false positives and false negatives.

## Project Outcome
Presented this project in an intercollegiate ML case study competition and secured 3rd rank.
